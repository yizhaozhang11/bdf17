# Agent Instructions

## SageMath Scripts

- Use the conda environment `sage` for all `*.sage` files.
- Run Sage scripts with `conda run -n sage sage <sagefile>.sage`.
- If `conda` is not available in a non-interactive shell, initialize it first with `source "$HOME/miniconda3/etc/profile.d/conda.sh"` and then run `conda run -n sage sage <sagefile>.sage`.
